# Samuel Odame Adjei-Larbi — GitHub Portfolio

## Publish on GitHub Pages

1. Open the `samuelodame.github.io` repository.
2. Upload `index.html` to the repository root.
3. Commit the change.
4. Go to **Settings → Pages**.
5. Under Build and deployment, select **Deploy from a branch**.
6. Select `main` and `/ (root)`, then save.
7. Visit `https://samuelodame.github.io/`.

The portfolio already includes the supplied email and WhatsApp contact details.
